How to read this

  • This run is MSA-only and template-free. Every one of these structures is in the PDB today, so enabling templates would hand the model its answer and destroy the blind-target property of the CASP15 set.
  • The MSAs are ColabFold MMseqs2, not AlphaFold’s own jackhmmer/HHblits triple — no sequence databases are installed on this machine. That, plus one model instead of five and no relaxation, is why this run does not reproduce the published baseline exactly.
  • Δ columns compare like with unlike on purpose. For the CASP15 set the baseline is a different group’s v2.2 run with its own MSAs; a positive Δ means better MSAs or a newer parameter set helped, not that the target stopped being hard.
  • Rows still below TM 0.8 after this run are the ones worth aiming test-time training at — the failure survives a modern MSA.
